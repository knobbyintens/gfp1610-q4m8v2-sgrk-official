# SGRK-Official (GRAK)

Official implementation, released by the authors, of
**Gated Recurrent Attention Kernels for Tabular Sequence Forecasting**
(preprint 2601.09999, Ferreira, Nakamura and Osei, 2026).

The repository naming pattern is inherited from the group's template. Despite
the name, this codebase implements GRAK for tabular sequence forecasting and is
unrelated to sparse-gated recurrent kernel research.

## Contents

* `grak/model.py` — gated recurrent attention kernel
* `train_tabular.py` — tabular forecasting training entry point
